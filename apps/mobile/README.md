# Tulu mobile caller simulation

Public, responsive web experience that demonstrates how a caller reaches Tulu from a familiar phone interface.

## Commands

Run these from the repository root:

```bash
pnpm dev:mobile
pnpm build:mobile
pnpm preview:mobile
```

For an independent deployment, use `apps/mobile` as the project root and `dist` as the build output directory.

This application is currently an interface simulation. It does not place calls, access a microphone, connect to the agent backend, or submit healthcare requests.
